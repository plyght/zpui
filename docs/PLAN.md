# zpui + zeron: status and plan

zpui is a Zig 0.17 port of [zui](https://github.com/zeronsh/zui) (zeronsh's fork of Zed's gpui).
`apps/zeron` is a Zig rewrite of the [zeron](https://github.com/zeronsh/zeron) desktop client on top of it.
The zeron Rust engine/daemon is unchanged; the client talks to it over its localhost WebSocket JSON-RPC.

## Conventions

- Zig 0.17.0 only. `@cImport` is gone — C headers go through `b.addTranslateC`.
- Container types inside generic functions must reference the generic parameter if they hold
  per-instantiation state (see `cachedSel` in `src/platform/mac/objc.zig`).
- Every port that has a Rust counterpart keeps a parity test fed by fixtures dumped from the Rust code.
- macOS is verified in CI (`.github/workflows/ci.yml`); Apple Silicon runners have no Metal device,
  so GPU jobs run on `macos-15-intel`.
